STEP 1 — Build M5: seller analytics, membership & referrals, platform analytics

Scope:
1. Event tracking:
   - First-party, privacy-safe tracking of: seller profile view, listing view, listing card impression in search/carousels, wishlist add, enquiry started, quotation sent/accepted, valuation requested from a listing, follow.
   - No PII in events. The visitor ID is a random first-party cookie, hashed with a daily salt.
   - Dedupe views per visitor per item per day. Exclude bots, admins, valuators, and sellers viewing their own pages.
   - Rate-limit the tracking endpoint so views can't be inflated.
   - A daily rollup job (npm run analytics:rollup, documented with a schedule) writes aggregates. Dashboards read aggregates, not raw events. Raw events are kept 90 days, then deleted by the same job.
2. Seller analytics (/seller/analytics):
   - Range 7/30/90 days, with KPI tiles and trend vs previous period: profile visits, listing views, impressions, wishlist adds, enquiries, conversion (views → enquiries), response rate, median first-response time (from M3 conversations), quotation acceptance rate, valuation requests, followers.
   - Line chart over time, top listings table, and CSV export.
   - Sellers only ever see their own data.
3. Followers ("subscribers" in the brief): buyers and other sellers can follow a seller. Followers get notified when that seller publishes a new listing (respecting notification preferences). The follower count shows on the portfolio.
4. Membership (Free / Premium / Elite):
   - Tier rules are admin-editable in a table, with these placeholder defaults (labelled "pending client confirmation"):
     - Free: 25 active listings, 30-day analytics.
     - Premium: 100 active listings, 1 featured slot, Premium badge, ranking boost in the sellers directory and "top sellers" carousel, 90-day analytics. Unlocks at 5 qualified referrals OR 50 followers, plus response rate ≥ 70%.
     - Elite: unlimited listings, 3 featured slots, Elite badge, top priority placement, 12-month analytics + CSV export. Unlocks at 20 qualified referrals OR 250 followers, plus response rate ≥ 85% and an average rating ≥ 4.5 from non-demo reviews.
   - A pure, well-tested tier evaluation engine runs in the rollup job.
   - Upgrades are immediate. Downgrades get a 14-day grace period. Sellers over a lower limit keep their listings but can't publish new ones.
   - Admin can manually set a tier with a reason (audit logged).
   - All limits are enforced on the server.
5. Seller membership page (/seller/membership): current tier and badge, progress bars toward the next tier for each criterion, a benefits comparison table, upcoming benefits, and "Upgrade" and "Rewards" buttons that show "Coming soon" (no payments).
6. Referrals: each seller gets a referral link/code, and the seller registration form accepts ?ref=.
   - A referral counts only when the referred seller is approved AND has published at least 1 listing.
   - Block self-referral. Flag suspicious referrals (same IP or device cookie, or same email domain in bulk) for admin review.
   - Admin can void a referral.
   - The referrer is notified when a referral qualifies.
7. Admin:
   - Memberships list with tier filter and manual override.
   - Tier rules editor.
   - Referrals list with flagged queue and void action.
   - Platform analytics dashboard with signups (buyers/sellers), seller approvals, listings published, enquiries, conversations, quotations, valuations, active users, top categories and top searches. 7/30/90 days with CSV export.
   This replaces "platform analytics" in M6; update ROADMAP.md.
8. Demo seed: demo analytics history (90 days of rollups), followers, referrals, and demo sellers on each tier. All labelled "Demo", respecting ALLOW_DEMO_SEED.
