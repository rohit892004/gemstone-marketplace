# Demo photos

These photos are from Pixabay and are used only for the local demo seed (`npm run db:seed:demo` and `npm run db:seed:m6`). They are not product photography and must not be used in production.

- Credits (photographer, Pixabay page and original size for each file) are in `docs/design/IMAGE-CREDITS.md`.
- Pixabay content is free to use under the Pixabay Content License, which does not require attribution. The licence summary is in the same file.
- File names are kept as they came from the source set: `sapphire-*`, `ruby-*`, `emerald-*`, `diamond-*`, `amethyst-*`, `opal-*`, `pearl-*`, `loose-dark-*` and `workshop-*`.
- The seeds read these files, run them through the media pipeline and store the results in local storage. The originals in this folder are never served.
